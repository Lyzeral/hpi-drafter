# hpi-drafter · 现病史整理技能

面向精神科及医学病历的**现病史（History of Present Illness, HPI）整理与改写技能**。将入院记录、出院记录、门诊病历等原始材料（多为病历系统截图）重构为可直接录入的规范一段式现病史。

## 功能

- **跨页信息抽取**：多页入院/出院记录、门诊病历按时间线拼接，抽取历次诊疗时间、诊断、用药、剂量、疗效、依从性与风险行为
- **症状群叙事**：按感知觉异常、思维内容异常、情感症状、意志行为、认知功能、伴随症状六群重组，避免按时间流水账堆砌
- **专科术语转换**：将精神检查/诊断性术语（幻听、被害妄想、思维奔逸、自知力等）转换为描述性现病史语言
- **诊断规范**：诊断名称一律加中文引号（如“分裂情感性障碍”），诊断修正写“诊断修正为××”
- **药物剂量规范**：通用名 + 剂量单位 mg，住院最大剂量加 `Max_` 前缀并标注频次，如 `氟伏沙明 Max_300mg_Qn`、`氯氮平 Max_425mg/d`
- **复合句压缩**：一句承载多症状，一段式输出，固定以阴性症状与饮食睡眠二便体重收尾

## 目录结构

## 安装

1. 下载或克隆本仓库
2. 将 `hpi-drafter` 文件夹放入你的技能目录：
   - 豆包桌面端：`Doubao/skills/`
   - 或 Agent 的 `.user_skills/` 目录
3. 重启对话使技能加载

## 使用

新开会话后，上传病历截图/文字材料并给出触发语，例如：

- “帮我整理现病史”
- “根据上次住院记录和门诊病历写现病史”
- “按症状群重写现病史”

技能会自动匹配并按规范输出一段式现病史。

## 输出规范示例

- 诊断：诊断“精神分裂症”，诊断修正为“伴有精神病性症状的重度抑郁发作”
- 剂量：`喹硫平 Max_600mg/d`、`丙戊酸钠缓释片 Max_1000mg_Bid`、`棕榈酸帕利哌酮（善思达）150mg im once（2025-05-29）`
- 频次：Qd 每日1次 / Bid 每日2次 / Tid 每日3次 / Qn 每晚1次 / Qm 每晨1次 / Prn 必要时 / im 肌注

## 免责声明

本技能仅用于病历书写的格式规范化，所有诊断、剂量、时间均以原始病历为准，不生成虚构医疗事实；范例中的病例信息仅用于演示格式，实际使用须遵守所在医疗机构病历管理规定与患者隐私保护要求。
