# 药物剂量书写规范

现病史中的用药方案按本规范统一书写，确保可追溯、可核对、格式一致。

## 一、基本格式

- 普通剂量：`通用名 剂量_频次`，如 `氟伏沙明 300mg_Qn`
- 住院最大剂量：`Max_剂量_频次`，如 `氟伏沙明 Max_300mg_Qn`、`氯氮平 Max_425mg/d`
- 多药联用：以顿号连接，如 `予喹硫平 Max_600mg_Qn、丙戊酸钠缓释片 Max_1000mg_Bid、阿立哌唑 Max_20mg_Qd 等治疗`
- 给药途径不是口服时注明：`im`（肌注）、`iv`（静推）、`ivgtt`（静滴）、`ih`（皮下），如 `棕榈酸帕利哌酮（善思达）150mg im once（2025-05-29）`
- 单次给药：`once`，如 `氯硝西泮 2mg im once`
- 必要时给药：`Prn`，如 `阿普唑仑 0.4mg_Prn`

## 二、规则

1. **药名用通用名**；商品名首次出现时括注，如 `利培酮（维思通）`，后文只用通用名。
2. **剂量单位统一 mg**：原文为 g 时换算（1g = 1000mg），如 0.6g/d → 600mg/d；口服液（如利培酮口服液）保留 ml。
3. **住院期间出现“最大量/最大剂量”字样的，必须加 `Max_` 前缀**；门诊维持剂量、出院带药剂量不加 Max。
4. **频次必须来自原始记录**，原文未载频次只写日剂量时用 `/d`，严禁按临床习惯臆造 Qn/Bid。
5. 剂量含小数时保留原精度（如 12.5mg、0.875g → 875mg），不随意取整。
6. 同一药物在多次住院中重复出现，每次住院分别按当次最大剂量书写，不合并。
7. MECT 等非药物治疗写次数：`联合 MECT 6 次`。
8. 原文未记载剂量时只写药名，不补剂量（如“予舍曲林、丙戊酸钠等治疗”）。

## 三、频次缩写表

| 缩写 | 含义 | 缩写 | 含义 |
|---|---|---|---|
| Qd | 每日1次 | Qn | 每晚1次 |
| Qm | 每晨1次 | Bid | 每日2次 |
| Tid | 每日3次 | Qid | 每日4次 |
| Q4h | 每4小时1次 | Qod | 隔日1次 |
| Qw | 每周1次 | Qm(针剂) | 按医嘱每月1次（须忠于原文） |
| once/St | 单次/立即 | Prn | 必要时 |
| po | 口服 | im | 肌内注射 |
| iv | 静脉注射 | ivgtt | 静脉滴注 |

## 五、改写示例

- 原文“喹硫平（最大量0.6g/d）” → `喹硫平 Max_600mg/d`
- 原文“维思通（最大量5ml/d）” → `利培酮口服液 Max_5ml/d`
- 原文“氟伏沙明最大量300mg，每晚一次” → `氟伏沙明 Max_300mg_Qn`
- 原文“善思达150mg 2025-05-29 once，100mg 2025-06-04 once” → `棕榈酸帕利哌酮（善思达）150mg im once（2025-05-29）、100mg im once（2025-06-04）`
- 原文门诊“喹硫平0.3g/d、阿立哌唑30mg/d” → `喹硫平 300mg/d、阿立哌唑 30mg/d`
