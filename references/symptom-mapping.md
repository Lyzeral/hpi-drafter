# 症状群分类与术语转换表

现病史只允许出现**症状的描述性表述**，精神检查章节的诊断性术语一律禁用。改写时按下表转换；无对应条目时，用“患者/家属可见的客观行为 + 患者原话转述”表达。

## 一、症状群详解

### 1. 感知觉异常群
- 听觉：凭空闻声、听到旁人听不到的声音、对空谩骂/通话、与声音对话或争吵
- 视觉：凭空看到人影、人物或旁人看不到的事物
- 嗅味觉：凭空闻到异味、进食时尝到异常味道而拒食
- 躯体：凭空觉身上有虫爬、电流、异物感
- 写法要点：注明内容（议论/命令/评论）及患者反应（对话、服从、恐惧），但不写“命令性幻听”等术语。

### 2. 思维内容异常群
- 被议论/被针对：觉旁人谈话系针对、议论自己
- 被害：怀疑或坚信有人欲加害于己（下毒、跟踪、监视、窥视、谋害）
- 被洞悉：未将想法说出，已觉为他人知晓
- 关系：觉得旁人举动、电视网络内容均与己有关
- 疑病：坚信自己身患不治之症或身体器官腐坏
- 夸大/钟情/嫉妒：自命非凡、坚信某异性钟情于己、无端怀疑配偶不忠
- 写法要点：保留具体对象（如“尤其怀疑母亲”）和具体行为后果（拒食、报警、躲避）。

### 3. 情感症状群
- 低相：情绪低落、兴趣减退、愉悦感缺失、易疲乏、自我评价低、悲观消极
- 高相：情绪高涨、兴奋话多、精力充沛、易激惹、发脾气
- 焦虑：紧张担忧、坐立不安、反复思虑、心悸
- 混合：情绪起伏大、烦躁与低落交替
- 写法要点：注明持续时间、昼夜规律及与诱因的关系；混合特征中的短时兴奋须注明“持续半天至1天可自行缓解”等原文时限。

### 4. 思维与意志行为群
- 言语：话多/语少、语速快、语无伦次、自言自语
- 活动量：兴奋忙碌、行为被动疏懒、社交退缩
- 冲动：推搡、持械、砸物、追逐、爆粗口——一律写具体动作
- 自伤自杀：割腕、划手、掐手、吞药、跳楼、跳河——写清方式、次数、时间、诱因及是否被阻拦
- 强迫/怪异：反复检查、反复洗手、仪式动作、怪异姿势
- 写法要点：风险行为不可省略、不可笼统写“有自伤行为”。

### 5. 认知功能群
- 注意力难以集中、记忆力下降、学习成绩下滑、工作能力下降、厌学
- 写法要点：与功能损害挂钩（如“无法坚持学业”“成绩明显下降”）。

### 6. 伴随症状群
- 睡眠（入睡困难、早醒、多梦、嗜睡）、食欲（增减、拒食）、二便、体重变化、月经、疲乏、头晕等躯体诉述
- 阴性症状（原文否认项）：高热、抽搐、意识丧失、强迫症状、暴饮暴食或节食等。

## 二、禁用术语 → 描述性语言对照表

| 禁用（检查/诊断术语） | 现病史描述性写法 |
|---|---|
| 幻听、言语性幻听 | 凭空闻声、听到旁人听不到的说话声 |
| 评论性幻听 | 听到声音在议论、评价自己 |
| 命令性幻听 | 听到声音命令、催促自己做某事 |
| 幻视 | 凭空视物、凭空看到人影/旁人看不到的事物 |
| 幻嗅、幻味 | 凭空闻到异味；进食时尝到异常味道 |
| 幻触 | 凭空觉身上有虫爬、电流或异物感 |
| 被害妄想 | 怀疑/坚信有人欲加害于己 |
| 关系妄想 | 觉旁人谈话、举动均在针对或议论自己 |
| 被洞悉感 | 未语已觉内心想法为他人所知 |
| 被跟踪/被监视妄想 | 觉被人跟踪、监视、窥视 |
| 物理影响妄想 | 觉有仪器、电波在控制自己 |
| 夸大妄想 | 自命能力非凡、有特殊身份或财富 |
| 钟情妄想 | 坚信某异性钟情于己（可用原话引语） |
| 嫉妒妄想 | 无端怀疑配偶不忠 |
| 疑病妄想 | 坚信自己身患不治之症或器官腐坏 |
| 思维奔逸 | 话多、语速快、话题随境转移 |
| 思维迟缓 | 语量少、语速慢、反应迟钝 |
| 思维破裂、思维松散 | 语无伦次、胡言乱语、答非所问 |
| 思维被播散/思维化声 | 觉自己的想法被大声说出、为旁人知晓 |
| 病理性赘述 | 说话啰嗦、纠缠细节、难以打断 |
| 情感淡漠 | 对家人及周遭事物缺乏相应情感反应 |
| 情感不协调、情感倒错 | 写具体场景（如无故哭泣、笑着诉说悲痛事） |
| 易激惹 | 易发脾气、因小事暴怒 |
| 强制性哭笑 | 无诱因出现不能自控的哭笑 |
| 意志减退 | 行为被动、生活疏懒、不愿出门、兴趣丧失 |
| 意志增强 | 终日忙碌、不知疲倦、行事鲁莽 |
| 自知力缺失/不全 | 不承认自身有病、拒绝治疗；对病情认识不足 |
| 定向力障碍 | 无法准确辨认时间、地点、人物 |
| 行为紊乱 | 言行紊乱、行为异常（并紧跟具体行为） |
| 冲动行为 | 直接写动作（推搡、持械、砸物、追逐） |
| 木僵、亚木僵 | 不语不动、拒食、反应迟钝（写具体表现） |
| 强迫观念/行为 | 反复思虑、反复检查、反复洗手（写具体动作） |

## 三、句式模板（复合句压缩）

- 感知+思维合并：`出现凭空闻声、凭空视物，伴敏感多疑，常觉他人谈话系针对议论自己，甚至怀疑有人欲加害于己。`
- 情感+行为合并：`情绪低落持续加重，伴兴趣减退、动力不足，时因琐事烦躁，间有划手自伤。`
- 高相合并：`偶见花钱增多、兴奋话多、精力充沛，计划多且消费大，尚不影响正常生活。`
- 诊疗句：`于YYYY-MM-DD至YYYY-MM-DD第N次入我院，诊断“××”，予×× Max_××mg/d、×× Max_××mg_Qn 等联合治疗，联合 MECT N 次后好转出院。`（诊断加引号，剂量规范见 medication-format.md）
- 收尾句：`病程中否认高热、抽搐、意识丧失；近期胃纳差、睡眠差，大小便基本如常，体重无明显变化。`
